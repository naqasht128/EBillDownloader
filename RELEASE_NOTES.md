# E-Bill Downloader v1.0.0

### Initial Release
• Automated batch electricity bill downloading from PITC bill portals.
• Chrome DevTools Protocol (CDP) high-definition PDF capture.
• PyMuPDF (fitz) automatic whitespace cropping, centering, and A4 scaling.
• Optional serial number stamping on top-right of bill.
• Option to save separate individual PDFs or merge all bills into a single sorted PDF.
• VS Code Dark+ themed GUI with real-time progress bar, live counters, and log viewer.
• Hardware-locked licensing with failover device ID binding.
• Automatic in-app update notifications and silent installer integration.
• Dual installer package: Windows 10/11 x64 and Windows 7 x86 (with bundled VC++ runtime).
